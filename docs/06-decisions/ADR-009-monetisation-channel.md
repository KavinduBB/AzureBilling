# ADR-009 — Monetisation channel
Status: Proposed · Date: 2026-09-01

## Options
A. Stripe subscription billing (fast, direct).
B. Azure Marketplace / AppSource SaaS offer with Microsoft-handled billing (enterprise procurement friendly, MACC-eligible, higher setup effort).

## Recommendation
A for launch (Phase 1), B added in Phase 4 for enterprise tier. Free tier = universal floor, one tenant.
